# 采集体验与全局连接升级

## 本次改动

- 配置在当前采集弹窗上叠加打开，仅保存和取消；保存后自动刷新，取消不写入。
- Notion 全局只保留一个 Token，移除添加和切换连接的界面。

- Token 从按类型重复配置改为全局连接，只保留当前使用的一个 Token。
- 每次采集选择保存位置，Notion 按连接与作品 / 账号类别分别展示最近 6 个，支持搜索分页和链接解析。
- 单库多数据源显式选择；按成功保存记录提示用途冲突；按实时字段检查阻止不兼容保存。
- 新版数据源读写覆盖 schema 读取、更新、查询和创建记录，标题列通过映射保留。
- 取消右侧面板：先识别再打开单一居中弹窗，容纳选择器、结构化预览和任务结果；全局设置页独立。
- 仅采集当前页面，先预览再保存。公众号第三方历史与补充数据功能已移除。
- 保存任务逐项记录，支持只重试失败项、停止后续项和跨页面恢复。
- 本地记录兼容 `collected` 和 `cjdb_local_*`，可重新导出。
- 统一冷灰白底、红色强调与红黑墨镜入口，取消全量 Element Plus 与未使用的 Notion SDK 依赖。
- 增加 Vue 类型检查、规则测试和隔离浏览器回归。

## 配置兼容

首次访问新设置服务时，把 `storesByType` 或更早的 `stores` 迁移到 `cjdb_settings_v2`。旧配置保留当前使用的一个 Token，飞书保存位置按连接信息去重。旧存储键保留用于兼容与回退；迁移后的操作只更新新配置。

旧配置中的数据库不是已成功保存的证据，因此初始用途标记为空。只有新流程保存成功后才记录用途。默认配置个人访问令牌（PAT），已有连接 Token 兼容。相同令牌重复保存保留快捷库；更换 PAT 会更新作用域，因为个人身份 ID 无法识别工作区。同一连接机器人更新 Token 仍保留快捷库。

`cjdb_tasks` 保存最近 50 次任务；只有未完成项保留恢复数据，成功项不重复保留正文。若浏览器空间不足导致任务记录失败，面板提示用户核对保存结果。对于外部接口已写入但网络未能返回确认的情况，仍需要按目标库实际内容核对。

## 手工验收

1. 重新加载扩展并刷新已打开的采集页面。
2. 打开全局设置，确认旧连接和飞书配置仍在；添加或更新 Notion Token。
3. 在当前文章或笔记页点击墨镜图标，确认先识别再打开弹窗，先检查预览并确认，再选择数据库、确认字段提示并保存。
4. 再次采集，确认作品与账号的最近数据库分别显示，搜索位于最近列表上方。
5. 用同一目标采集另一种数据，确认出现用途冲突提醒；字段不兼容时不能继续。
6. 测试一个包含多个数据源的数据库，确认选择准确且写入落在目标数据源。
7. 使用本地保存，检查记录、CSV 和 Markdown / 媒体包。
8. 在批量任务中停止后续项或模拟一次失败，从面板和任务记录继续处理，核对成功项没有重复。
9. 检查小红书评论、搜索合集、账号、公众号当前文章和飞书文档的原始采集字段。

自动测试使用模拟外部接口，不能替代真实 Notion / 飞书权限和平台页面的验收。

## 后续授权方式

本轮采用全局 Token。OAuth 免填 Token 属于后续独立工作，需要公开集成和安全的令牌交换服务。
