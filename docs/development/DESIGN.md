# 当前界面与流程设计

正式实现以 Vue 组件为准；旧 HTML 原型仅保留为早期视觉参考。

## 两步决策

1. 识别网页内容，成功后打开预览。展示实际标题、正文、作者、图片和可用数据；用户确认内容与媒体选项后才进入存储页。识别失败不打开空弹窗。
2. 选择存储源和具体保存位置，再点击底部保存。预览快照不会被网页后续变化覆盖。返回预览保留媒体选项，重新确认后需要再次选择位置。

## 预览与缓存

- 预览服务于看清整批全貌：搜索合集用紧凑表格展示全部已采集项的标题、作者、点赞与时间，并展示关键词和总数；单篇内容集中展示真实字段和正文摘要。未获得的指标显示“—”，不伪装成零。
- 每次点击墨镜入口都从预览开始，包括上次在存储页关闭的情况；不替用户恢复到存储步骤。
- UI 不维护跨次预览缓存。每次入口从当前采集器读取最新页面数据与持续更新的标记缓存；同一 URL 下新加载的作品、评论及勾选变化必须进入下一次预览。采集器根据当前页面身份隔离标记缓存。仅在预览打开后固定本次结果，供确认保存。
- 预览底部只有“重新采集”和“确认”。重新采集先关闭预览、清除本次预览结果，再读取页面；失败不回退旧数据，修复页面后可以重试。

## 存储页布局

- 顶部紧凑摘要展示实际内容类型、数量、最多三个标题；搜索结果存在关键词时展示关键词。提供返回预览，不放静态示例数字或无说明占位信息。
- 存储源、配置、对应表单位于同一块有边界的区域。下拉框占据可用宽度，配置按钮紧随右侧，不放在全局标题栏。
- Notion 未配置时突出 Token 引导；飞书未配置时突出应用凭据引导。本地无需配置按钮。
- 已配置后依次展示搜索框、最多 6 个最近数据源胶囊、数据源列表。进入即加载数据源；搜索仅更新下方列表，最近使用始终保留。胶囊复用已有名称、字段信息，不发起独立详情请求。空列表不重复提供帮助入口。
- 标题栏“使用帮助文档”常态主题红，配置弹窗仍然只有保存和取消。
- 数据源列表在中间滚动，直接点选数据源。数据库与数据源选择规则见 [Notion 选择说明](NOTION-SELECTION.md)。

## 状态与安全

配置更新、来源切换、改选目标、查询变化、本地导出格式变化或取消混用确认都会使旧的保存目标失效，必须重新确认目标。选择不会立即写入内容，只有底部保存按钮执行写入。

扩展源 iframe 隔离凭据输入，Shadow DOM 隔离宿主页面样式。媒体下载、逐项保存、失败重试和停止逻辑沿用现有实现。


## 本轮三轮校验与取舍

1. 用户与产品：关闭后重开为何改变步骤？批量预览能否看到最后一条？修正为入口始终预览，批量表格展示完整采集结果；保留采集器的实时标记缓存，不保留跨次预览快照，不自动恢复存储步骤。
2. 设计与体验：快捷项是否占满结果区？同名来源能否区分？使用最多六个圆角胶囊，复用源名称和字段数；收紧固定区域间距，数据库区域独立滚动。不在胶囊里重复铺陈行数和完整字段列表。
3. 开发与可靠性：列表请求会不会被快捷选择取消？初始化配置会不会覆盖用户刚选的来源？URL 切换是否早于标记更新？分别拆分请求状态、在初始配置加载期间禁用来源下拉，并在搜索采集前同步标记。重新采集失败不得恢复旧快照，由浏览器回归验证。

保存位置直接展示数据源，去掉父数据库包装和展开层。正常列表每页一次搜索请求，元信息直接复用返回值；行数按需读取，选择与保存前仍实时校验。
