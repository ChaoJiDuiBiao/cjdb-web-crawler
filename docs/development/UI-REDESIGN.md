# 采集弹窗改版方案

状态：已按 v3 方案接入正式界面（2026-09-06），取代右侧面板。原型保留为视觉参考，正式行为以实际 Crawler 和数据库权限为准。

本次依据用户提供的品牌参考图调整：红黑墨镜图标、冷灰白底、红色强调；搜索前置；作品与账号的最近数据库隔离；先识别后打开弹窗。

## 产品定位与流程

面向内容创作者的随手采集工具：用户正在看内容，工具应帮助他快速确认内容和去向。采用单一居中弹窗，不再设置右侧面板。

流程：右下角图标 → 识别并读取当前数据 → 成功后打开采集弹窗 → 搜索或选择对应类型的最近数据库 → 预览确认 → 保存结果。点击瞬间不打开选库弹窗。未完成预览再次打开时恢复，避免重采集。

识别中入口显示进度环和短状态文字，防止重复点击；识别失败或无数据时在入口旁给出原因和重试提示，不打开空弹窗。媒体下载和实际写入仍在用户确认后执行。正式版等待真实识别 Promise，不添加人为延迟；草稿用约 1 秒模拟异步识别。

## 入口

采用 56 × 56 px 圆角方形图标入口，圆角约 17 px，离右边和下边各 24–28 px。取消长条按钮与常驻“采集”文字。墨镜图形沿用参考图品牌意象，红色斜带叠在深海军蓝底色上；用简化矢量轮廓保证小尺寸辨识度。

图标文件为 [collector-mark.svg](prototypes/collector-mark.svg)，用于设计草稿，正式入口使用同源 BrandMark 矢量组件；扩展安装图标保持现有资源。悬停 / 键盘聚焦显示“采集当前页面”，无障碍名称保持明确。默认无持续动画；识别期间外围进度环转动，避免旋转品牌图案。轻阴影和约 2 px 悬停位移，尊重减少动态效果偏好。

## 弹窗布局

宽度默认 720 px，预览可扩至 840 px；最大高度 84vh，小屏距边缘至少 16 px。圆角 20 px，正文区滚动，标题与底部操作区固定。

标题左侧“采集内容”及当前类型，右侧依次为“配置”“帮助”、关闭。配置是低频操作，用文字加线性齿轮图标，避免抢占标题位置。每一步保留入口；在当前采集弹窗上叠加配置弹窗，只有保存和取消，没有右上角关闭；保存后自动刷新配置，取消不写入。输入表单位于扩展来源的隔离 iframe，现有密钥不回填网页。

选择目标时先显示已识别的内容摘要，再依次显示：

1. “保存到哪里？”
2. 数据库搜索框与搜索按钮。
3. “最近使用”及作品 / 账号分类切换。
4. 当前类别最近使用的最多 6 个库（2 列 × 3 行）。

搜索有关键词时下方标题改为“搜索结果”；清空恢复当前类别最近使用。连接管理、技术 ID、媒体选项等信息不堆在首屏；连接异常时在相关位置提示。

### 作品 / 账号隔离

最近列表的作用域为“连接 ID × 数据类别”：作品包含笔记、文章、搜索合集、文档；账号包含账号资料。每类各保留最多 6 个快捷库和自己的上次选中项。账号库不会占用作品最近名额，反之亦然；一个库若经用户确认用于两类，允许分别出现在两个列表。旧历史无法确定类别时，不随意塞进两个列表，保留搜索能力，后续选择时记录明确类别。

默认类别取决于实际识别结果。若页面同时可采集作品和作者账号，切换类别要使用对应数据并在必要时重新识别，不能仅改标签就把文章当账号写入；只支持一种数据的页面不展示无效切换项。草稿为了比较两类视觉提供两组模拟数据，切换时同时更换摘要和目标列表；也可通过背景页的模拟入口验证默认类别。

最近使用与搜索结果是不同概念：正式搜索可列出已授权数据库，仍做用途及字段检查；最近列表严格按类别隔离，不把其他类别的历史混入。草稿搜索仅筛选当前类别的示例库，不代表真实 API 搜索。

预览时展示封面、标题、作者和摘要；正文、评论、附加数据按需展开。保存位置压缩为一行“保存到：作品素材库 · 更换”。底部左侧轻量帮助，右侧唯一主按钮“保存到作品素材库”。更换目标在原弹窗内切换视图，返回保留预览。

用途冲突紧邻目标显示琥珀色提示，并提供“换一个数据库”和显式继续确认。字段不兼容使用红色提示并阻止继续。未知用途不推断。任务失败保留内容并提供重试；关闭不等于取消，批量停止单独提供，等待当前项完成。

## 视觉规范

| 项目 | 规范 |
| --- | --- |
| 主背景 | #FFFFFF |
| 柔和底色 | #F5F6F9 |
| 主文字 / 次文字 | #1C202A / #727987 |
| 主色 / 悬停 | #E91D46 / #CD1339 |
| 分隔线 | #E4E6EC |
| 成功 / 警告 / 错误 | #16734B / #9A5B00 / #B42318，配浅色背景及文字说明 |
| 字号 | 标题 22，正文 14，辅助 12–13 px |
| 间距 | 8 px 基础节奏；正文内边距 28 px |
| 圆角 | 弹窗 20，目标卡片 12，按钮 10，入口 17 |
| 动效 | 160–200 ms 淡入与轻微位移；尊重减少动态效果偏好 |

品牌深色 #080F1E 仅用于入口和少量品牌展示，选中底色使用 #FFF1F4。

不用全屏深色、重复套卡片、重阴影或整行蓝色说明框。色彩集中用于选中状态和主操作。键盘焦点可见；弹窗约束焦点，关闭后返回入口；关闭和停止含义分开。参考 [W3C 模态弹窗模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。

## 交流与反馈入口

采集弹窗右上角使用主题红色的“加我微信 交流学习”入口。点击后在当前页面叠加二维码弹窗，显示作者微信二维码、添加备注「超级对标插件」；关闭后回到原采集流程并恢复焦点。

二维码随扩展打包，来源为 `docs/showcase/images/author-qr.png`，运行时使用 `public/contact-qr.png`。更新二维码时同步两处文件。内嵌使用指南和后台打开帮助页的服务已移除；安装说明维护在 README。

## 实施与验收

1. 去掉 CollectPanel 的 aside 和展开中间态，改为单一弹窗流程容器。
2. 把真实识别和内容读取移到弹窗打开之前，失败不弹空选库框。目标选择、预览、结果改为容器内视图，避免嵌套模态。
3. 全局样式换为红黑品牌 + 冷灰浅色规范，设置页与工具栏统一；入口替换为墨镜图标。
4. 增加配置和情境帮助入口；迁移“收起侧栏”测试为“关闭并恢复弹窗”。
5. 检查选择数据库、预览、更换目标、返回、失败重试全过程状态不丢失；运行时入口状态与任务一致。
6. 最近使用改为连接与作品 / 账号分类隔离，每类最多 6 个；验证切换后列表和选中项一致。
7. 验证窄屏、键盘、宿主样式隔离与原有存储流程。
