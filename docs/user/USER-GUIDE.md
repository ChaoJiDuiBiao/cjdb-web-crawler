# 安装与使用指南

[返回项目介绍](../../README.md)

## 安装插件

1. 打开 [发行下载页](https://github.com/ChaoJiDuiBiao/cjdb-web-crawler/releases)，下载作者提供的插件 ZIP 安装包，不要选择 GitHub 自动生成的 Source code 源码包。
2. 将 ZIP 解压到一个固定文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
5. 刷新需要采集的网页，点击页面右下角的墨镜图标。

如果发行页尚无安装包，需要等待作者发布；已有作者提供的 ZIP 可以直接从第二步开始。

## 第一次采集

打开笔记、文章或文档后，先让内容加载完成，再点击墨镜图标。

预览里可以查看本次内容与媒体数量。需要更多评论或搜索结果时，关闭预览，继续在原网页加载，再点击采集。每次都会读取最新已加载、已标记且选中的内容。

发现数据偏差时点击“重新采集”。确认无误后，点击“确认”进入保存位置选择。

“保存图片与视频文件”开启时会尝试下载上传媒体；关闭时保留链接。视频数量按实际取得的有效视频地址计数，不代表媒体已经下载完成。

## 配置 Notion

1. 根据 [Notion 官方个人令牌指南](https://developers.notion.com/guides/get-started/personal-access-tokens) 创建个人访问令牌（PAT）。
2. 创建时选择目标工作区，启用 **Notion API** 能力，设置有效期并复制令牌。
3. 在保存位置页面选择 Notion，点击旁边的“配置”，粘贴令牌并保存。作品和账号共用这一份配置。
4. 搜索保存位置：支持名称、数据库链接或数据源 ID。点击列表中的数据源即可选中，再点击底部保存按钮。

个人令牌使用你的访问权限，无需逐个数据库添加连接。找不到目标时检查令牌所属工作区及你的页面权限。

最近使用最多显示 6 个，作品与账号分别记录。更换个人令牌后需要重新选择保存位置。旧连接 Token 仍兼容，但仍需在 Notion 为连接授权。

选择数据源时不检查字段；实际保存时检查兼容性，缺失字段会补充，类型不兼容会提示失败。

## 配置飞书

准备应用的 App ID、App Secret 和目标多维表格 Wiki 链接，链接需包含目标表的 `table` 参数。确保应用有相应读写权限及目标表访问权限。

在存储源旁点击“配置”，选择飞书，填写保存位置名称与上述信息后保存。随后在采集弹窗中选择该位置。

## 保存到本地

本地无需账号。可以只保存到浏览器记录，也可以导出 CSV、Markdown / 媒体包。

在插件设置中的“本地记录”查看或重新导出。浏览器数据清理可能影响本地记录，重要内容建议另行导出保存。

## 常见问题

**没有看到采集按钮？**  
确认当前平台和页面类型受支持，安装或更新后刷新网页。抖音仍在完善中。

**为什么图片或视频显示 0？**  
表示本次没有取得对应的有效媒体地址。等待页面加载后重新采集。小红书视频读取当前笔记匹配的页面视频元数据，未获取时不会将播放器临时地址计为视频。

**保存很慢？**  
图片和视频需要下载、上传，耗时通常比纯文字长。不需要媒体文件时可以关闭媒体选项，保留链接。

**保存失败怎么办？**  
查看结果中的具体原因，修正配置或权限后重试。重试会跳过已确认成功的项目。若写入成功但网络响应丢失，先核对目标库，避免重复保存。

**怎样更新？**  
下载新版本并解压。在扩展管理页加载新的构建文件夹；如果直接更新了原加载目录，点击重新加载。最后刷新采集网页。不要先卸载插件，以免丢失本地配置和记录。
