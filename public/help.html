开始采集连接 Notion数据库用途失败与重试本地导出

开始采集

  1. 打开支持的小红书、公众号文章或飞书文档页面，点击右下角墨镜图标。
  2. 识别中请保持页面打开。成功后弹出真实预览；没有识别到内容时，在入口旁查看原因并重试。
  3. 预览整批内容和关键数据，确认心里有数后点击“确认”。发现偏差时，点击其左侧“重新采集”，重新读取当前页面。
  4. 从存储源下拉框选择本次保存位置。未配置时，点击配置引导按钮，在同页弹窗填写该来源的凭据。Notion 搜索框支持数据库 URL、Data source ID、数据库名称。列表直接展示数据源，点击即可选择；数据库链接会列出其中的数据源；搜索框下方以胶囊显示最近使用的最多 6 个数据源，作品与账号分别记录；下方默认加载数据库列表，搜索仅更新列表。
  5. 点击底部“保存到…”完成保存。可以返回预览检查；关闭弹窗后再次点击图标，总是读取最新已加载、已标记且选中的内容并重新进入预览。

存储源下拉框右侧的“配置”在当前页面叠加弹窗，只提供保存和取消。保存后自动刷新；留空保留已有密钥，取消不修改。仅采集当前页面的内容。

配置 Notion 个人令牌

  1. 参照 Notion 官方个人令牌指南，在 Developer portal 的 Personal access tokens 中创建令牌。
  2. 选择需要保存内容的工作区，启用 Notion API 能力，设置有效期并复制令牌。
  3. 在插件配置中粘贴个人访问令牌（PAT），保存后即可搜索并选择数据源。所有采集类型共用一个令牌。

个人令牌使用你的页面权限，无需给数据库添加连接。一个令牌属于一个工作区；搜索仅显示当前令牌可访问的内容。令牌过期或被撤销时需要重新创建并更新。更换个人令牌后重新选择保存位置，最近使用按令牌隔离，避免混用其他工作区。

已有连接 Token 仍兼容，留空保存不会删除；连接 Token 仍需要在 Notion 为连接授权，不能自动转换为个人令牌。

数据库信息与滚动

数据源直接展示名称、创建日期和字段数。“查看详情”可查看字段并打开 Notion 核对；点击“读取行数与信息”才统计行数，不影响正常加载和选择。名称检索还有后续批次时，可点击“继续检索更多”。超过一页显示“至少 N 行”，点击“继续统计行数”逐页统计，完成后显示准确数量。统计失败时可重试，不影响选择数据库。搜索结果和字段在中间区域滚动，不会撑开页面。

作品与账号的数据库

作品最近库与账号最近库独立记录，每个连接、每类最多展示 6 个。页面不支持的类型不能切换。旧记录用途未知时不会猜测归类，可通过搜索重新选择。

数据库被本工具用于不同内容时会显示提醒。你可以换库，或明确确认混合使用。字段类型不兼容时必须更换或调整字段，不能直接继续。缺失字段会在确认保存时补充。

失败与重试

连接失效：打开配置更新 Token。找不到库：检查授权并刷新。没有写入权限：检查令牌的 Notion API 能力及你对目标页面的权限。请求限流或网络失败：稍后重试失败项。

逐项结果会标记成功、失败、待处理。重试跳过已确认成功的项；停止后续保存会等待当前项结束。关闭弹窗不等于停止任务，请保持原网页打开。全局“任务结果”可恢复未完成保存。

若外部 API 已写入但网络未返回确认，请先核对目标库再重试，避免重复。媒体回退为外链或导出失败会单独提示，不会把已保存内容标记成失败。

本地存储与导出

本地无需账号。可仅保存在浏览器，或同时导出 CSV、Markdown / 媒体包。“本地记录”可重新导出，关闭媒体选项时保留链接。数据保存在当前浏览器配置中。

飞书保存位置在全局配置中添加名称、App ID、App Secret 和包含目标表参数的 Wiki 链接。
