# 小红书数据采集到 Notion - 产品设计

## 一、核心功能

### 1.1 笔记采集
在小红书笔记页面添加"采集"按钮，一键采集笔记数据到 Notion

### 1.2 账号采集
在小红书账号主页添加"采集账号"按钮，采集账号信息及笔记列表到 Notion

## 二、数据模型

### 2.1 笔记数据库（Notes Database）

| 字段名 | Notion 类型 | 说明 | 用途 |
|--------|-------------|------|------|
| 标题 | Title | 笔记标题 | 主键 |
| URL | URL | 笔记链接 | 去重标识 |
| 发布时间 | Date | 发布日期 | 时间维度分析 |
| 正文 | Rich Text | 笔记正文内容 | 内容存档 |
| 图片 | Files & Media | 图片链接列表 | 视觉内容 |
| 标签 | Multi-select | 笔记标签 | 分类筛选 |
| 点赞量 | Number | 点赞数 | 数据指标 |
| 收藏量 | Number | 收藏数 | 数据指标 |
| 评论量 | Number | 评论数 | 数据指标 |
| 作者 | Relation | 关联到账号数据库 | 关联作者 |
| 作者粉丝量 | Number | 采集时作者粉丝数 | 快照数据 |
| 采集时间 | Date | 数据采集时间 | 更新追踪 |

### 2.2 账号数据库（Accounts Database）

| 字段名 | Notion 类型 | 说明 | 用途 |
|--------|-------------|------|------|
| 昵称 | Title | 账号昵称 | 主键 |
| 账号 ID | Text | 小红书账号 ID | 去重标识 |
| 主页 URL | URL | 账号主页链接 | 访问入口 |
| 头像 | Files & Media | 头像图片 | 视觉识别 |
| 笔记数 | Number | 笔记总数 | 数据指标 |
| 获赞数 | Number | 总点赞数 | 数据指标 |
| 粉丝数 | Number | 粉丝总数 | 数据指标 |
| 关注数 | Number | 关注总数 | 数据指标 |
| 笔记列表 | Rich Text | 主页笔记列表（标题+点赞） | 内容快照 |
| 采集时间 | Date | 数据采集时间 | 更新追踪 |

## 三、核心技术设计

### 3.1 去重策略

**笔记去重**
- 唯一标识：URL
- 逻辑：采集前通过 Notion API 查询 URL 字段
- 存在：更新数据（点赞、收藏、评论等动态数据）
- 不存在：创建新条目

**账号去重**
- 唯一标识：账号 ID
- 逻辑：采集前通过 Notion API 查询账号 ID 字段
- 存在：更新数据（粉丝数、笔记数、笔记列表等）
- 不存在：创建新条目

### 3.2 字段自动创建

**初始化流程**
1. 脚本启动时检查 Notion 数据库结构
2. 对比所需字段与现有字段
3. 自动创建缺失字段（通过 PATCH /databases/{id}）
4. 完成后显示"采集"按钮

**字段定义映射**
```javascript
笔记数据库字段 = {
  "标题": { title: {} },
  "URL": { url: {} },
  "发布时间": { date: {} },
  "正文": { rich_text: {} },
  "图片": { files: {} },
  "标签": { multi_select: {} },
  "点赞量": { number: {} },
  "收藏量": { number: {} },
  "评论量": { number: {} },
  "作者粉丝量": { number: {} },
  "采集时间": { date: {} }
}

账号数据库字段 = {
  "昵称": { title: {} },
  "账号ID": { rich_text: {} },
  "主页URL": { url: {} },
  "头像": { files: {} },
  "笔记数": { number: {} },
  "获赞数": { number: {} },
  "粉丝数": { number: {} },
  "关注数": { number: {} },
  "笔记列表": { rich_text: {} },
  "采集时间": { date: {} }
}
```

### 3.3 数据提取策略

**优先级**
1. DOM 元素提取（最准确）
2. window.__INITIAL_STATE__（备用）
3. API 请求拦截（高级方案）

**图片处理**
- 提取所有图片 URL
- 存储为 Notion Files 类型（外链）

**笔记列表格式**
```
📝 笔记标题1 | ❤️ 1.2w
📝 笔记标题2 | ❤️ 8956
...
```

## 四、核心流程

### 4.1 笔记采集流程

```
用户点击"采集"按钮
  ↓
提取笔记数据（10个字段）
  ↓
查询 Notion（通过 URL）
  ↓
存在？
  ├─ 是 → 显示确认框 → 更新数据
  └─ 否 → 显示确认框 → 创建条目
  ↓
显示成功/失败状态
```

### 4.2 账号采集流程

```
用户点击"采集账号"按钮
  ↓
提取账号基本信息
  ↓
提取主页笔记列表（滚动加载）
  ↓
格式化笔记列表为文本
  ↓
查询 Notion（通过账号ID）
  ↓
存在？
  ├─ 是 → 显示确认框 → 更新数据
  └─ 否 → 显示确认框 → 创建条目
  ↓
显示成功/失败状态
```

### 4.3 初始化流程

```
脚本加载
  ↓
注入样式
  ↓
检查 Notion 数据库结构
  ↓
创建缺失字段
  ↓
注入采集按钮
  ↓
监听页面变化（SPA 路由）
```

## 六、配置管理

### 6.1 配置项
- Notion API Key（用户输入）
- 笔记数据库 ID（用户输入）
- 账号数据库 ID（用户输入）

### 6.2 配置界面
通过 Tampermonkey 菜单命令：
- "配置笔记数据库"
- "配置账号数据库"
- "重置配置"

## 七、关键技术点

### 7.1 数据提取
- 笔记正文：提取 `.note-content` 或类似容器的文本
- 图片列表：提取所有 `img` 标签的 `src`
- 标签：提取 `.tag` 或类似元素
- 发布时间：提取时间元素或从 `__INITIAL_STATE__` 获取

### 7.2 账号笔记列表
- 滚动加载：模拟滚动到底部，等待加载完成
- 提取逻辑：遍历笔记卡片，提取标题和点赞数
- 格式化：生成 Markdown 格式文本

### 7.3 性能优化
- 按钮注入：使用 MutationObserver 监听 DOM 变化
- 数据缓存：避免重复查询数据库结构
- 异步处理：所有 API 请求使用 Promise

## 八、错误处理

### 8.1 常见错误
- API Key 无效：提示用户检查配置
- 数据库不存在：提示用户检查 Database ID
- 网络错误：提示重试
- 数据提取失败：显示调试信息

### 8.2 降级方案
- DOM 提取失败 → 使用 window.__INITIAL_STATE__
- 图片提取失败 → 跳过图片字段
- 部分字段缺失 → 仅更新可用字段
