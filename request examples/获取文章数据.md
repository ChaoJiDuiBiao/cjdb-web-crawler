功能：根据公众号文章 URL 获取文章数据
API：/fbmain/monitor/v3/read_zan_pro
请求方式：POST
请求头：
Content-Type: application/json
Body:
{
  "url": "{{公众号URL}}",
  "key": "{{key}}",
  "verifycode": ""
}

Response
```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "read": 100001, // 阅读量
        "zan": 1536, // 拇指赞
        "looking": 404, // 爱心赞
        "share_num": 8969, // 转发量
        "collect_num": 541, // 收藏量
        "comment_count": 95 // 评论数
    },
    "cost_money": 0.06, 
    "remain_money": 28.845 
}
```
